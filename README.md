# GoDaddy Landing Page Clone — Key Details

A simple and clean clone of a GoDaddy-style landing page built using **pure HTML + CSS**, focusing on layout, responsiveness, and UI design.

---

## 🔑 Project Highlights

* Fully responsive navbar with hamburger menu (CSS only).
* Promo banner with offer details.
* Domain search bar UI.
* Hero video section with overlay text + info card.
* Marketing info sections with feature boxes.
* Auto-sliding template gallery (CSS keyframe animation).
* Multi-column footer with categories.

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3** (Flexbox, Media Queries, Animations)
* Assets: PNG images & MP4 hero video

---

## 📁 File Structure

```
index.html      → Main Page
next.css        → Styling
assets/         → Images + Video (optional folder)
README.md       → Documentation
```

---

## 🚀 How to Run

1. Clone the repo.
2. Open `index.html` directly **OR** run via Live Server.

Recommended:

```
python -m http.server 5500
```

Then open: `http://localhost:5500`

---

## 🧩 Customization

* Replace images/videos with your own.
* Modify colors, layout, and components in `next.css`.
* Add JS for hamburger animation or dynamic features.

---

## 📌 Notes

* Hero section absolute elements may need extra media queries.
* Gallery uses CSS-only animation—lightweight but not swipeable.
* Add alt text & ARIA labels for accessibility.
